# Contributing

Thanks for taking the time to contribute! This project is intentionally small
and focuses on providing a clean example for badges and automation.

## Getting Started
1. Fork the repository and create a feature branch.
2. Create a virtual environment and install dependencies:
   - `python -m venv .venv`
   - `source .venv/bin/activate`
   - `pip install -e .[dev]`
3. Make your changes with tests and documentation updates as needed.

## Quality Checks
- Run formatting and lint checks: `ruff check .`
- Run the test suite: `pytest`

## Pull Requests
Please include:
- A clear description of the changes.
- Tests covering behavior changes.
- Documentation updates when adding or changing public behavior.

By contributing, you agree that your contributions will be licensed under the
MIT License.
